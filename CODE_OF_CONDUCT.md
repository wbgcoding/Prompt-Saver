# Code of conduct

This repository's issues, pull requests and reviews are for working on this project. Everyone taking
part is expected to keep it that way.

## Expected

- Stay on topic and assume good intent.
- Criticise code, ideas and decisions, not people.
- Respect a decision once it is made, or bring new facts.

## Not accepted

- Insults, harassment, threats, discriminatory or sexual remarks.
- Publishing someone's private information.
- Spam, advertising, or repeatedly pushing a request that was already declined.

## Reporting

Use GitHub's **Report content** menu on the comment, issue or pull request and choose
**Report abuse**; GitHub reviews it privately. The maintainer also moderates directly. Security
problems go through [`SECURITY.md`](SECURITY.md) instead.

## Consequences

Depending on how serious it is: a comment is edited, hidden or deleted, a thread is locked, or the
account is blocked from the repository. The maintainer decides.
